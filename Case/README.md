# Framework Laptop 16 Case
This is a 3D-printable case to enable re-use of the Framework Laptop 16 Mainboard.

Note that you'll want to use filament that is designed for high temperatures, like ABS, PETG, or PP.

It is sized to be able to fit on the print bed of a Prusa XL, but there is also a split
version to enable smaller printers.

You'll need to print 8x of the "Connect Pin 1" to connect the top and bottom halves to each other.

If you're printing the split version, you'll also need 5x of the "Connect Pin 2".
